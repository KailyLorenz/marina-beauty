# Темы Marina Karper

Одна система цветов, **четыре готовых оформления**. Все секции используют CSS-переменные из `styles/theme.css`.

| ID | Название | Характер |
|---|---|---|
| `ice` | Ледяная бирюза | Чистый, светлый, фирменный бирюзовый акцент (по умолчанию) |
| `graphite` | Жемчужный графит | Более сдержанный, редакционный, холодный сланцевый акцент |
| `orchid` | Ледяная орхидея | Элегантный холодный лиловый акцент |
| `taupe` | Cool Taupe Luxury | Холодный беж, глубокий серо-коричневый и бирюза в Hero |

## Как дать Марине выбрать

Откройте сайт, прокрутите вниз до Footer — там блок **«Цветовая тема»** с четырьмя вариантами. Нажатие перекрашивает сайт сразу, а выбор сохраняется **только в браузере посетительницы**.

## Как зафиксировать выбранную тему для всех новых посетителей

Откройте `config/themes.js` и поменяйте:

```js
export const DEFAULT_THEME = 'ice';
```

на `graphite`, `orchid` или `taupe`.

**Важно:** уже сохранённый выбор в вашем браузере имеет приоритет над умолчанием. Чтобы увидеть новую тему с нуля — откройте приватное окно или очистите `localStorage` ключ `marina-karper-theme`.

## Как добавить 5-ю тему

1. Скопируйте готовый блок `html[data-theme="taupe"] { ... }` из `styles/theme.css`.
2. Назовите новый блок, например `html[data-theme="blue"]` и поменяйте его переменные.
3. В `config/themes.js` добавьте объект `{id:'blue', label:'...', description:'...', swatches:['#...', '#...', '#...']}`.

**Больше ничего изменять не нужно:** переключатель формируется из списка автоматически, а все компоненты получают цвета через CSS-переменные.

## Рекомендация

Для текущего портрета Марины сначала покажите `ice` и `taupe`, чтобы сравнить свежую и более строгую гаммы. Ключевой эффект создаёт **светлый фон, крупная типографика и локальный бирюзовый акцент**, а не массовая цветная заливка.

## Перед публикацией

Переключатель оставлен видимым для согласования вариантов. После утверждения темы его можно убрать из `components/layout/Footer.jsx` (`<ThemeSwitcher />`) без влияния на оформление страницы. Сохраните выбранный ID в `DEFAULT_THEME`.
