## Установка

Распакуйте архив полного проекта в новую папку, затем из неё выполните:

```powershell
npm install
npm run dev
```

Если используете архив только изменений, скопируйте файлы в текущий проект и **вручную удалите app/layout.js** (layout.jsx оставить).

Ссылку на оплату GetCourse нужно заполнить в config/site.js перед публикацией.
