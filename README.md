# Marina Karper — Premium Editorial · 4 Themes

Полный лендинг Next.js с новой фотографией в Hero, видеофрагментами, историями результатов, программой, ценой, FAQ и мобильной версией.

## Запуск в WebStorm / PowerShell (Node.js 16.20.2)

```powershell
node -v
npm install
npm run dev
```

Открыть http://localhost:3000

**Совместимые основные зависимости:** Next 13.5.11 + React 18.2.0. Архив специально **без старого package-lock.json** от Next 16, чтобы не поставить случайно неподходящую версию. Не копируйте старый lock-файл поверх этой версии.

## Четыре темы

В футере находится селектор из четырёх вариантов:

1. Ледяная бирюза (`ice`) — исходный фирменный образ.
2. Жемчужный графит (`graphite`) — строгий холодный премиальный вариант.
3. Ледяная орхидея (`orchid`) — более мягкий вариант.
4. Cool Taupe Luxury (`taupe`) — холодный беж и серо-коричневый taupe с бирюзовой кнопкой Hero.

Подробности: **[THEMES.md](./THEMES.md)**. Все токены находятся в одном файле `styles/theme.css`, а реестр тем и умолчание — в `config/themes.js`.

## Обновлённый образовательный блок

- `components/sections/ConcernsSection.jsx` — вместо личного фото Марины используется короткое **видео с моделью**. Превью — `/images/marina-model-explainer-poster.jpg`, само видео — `/videos/marina-practice-05.mp4`. Файл видео подгружается только по нажатию.
- `components/sections/ReasonsSection.jsx` — три существующие анатомические иллюстрации `/images/course-02.webp` ... `/images/course-04.webp` с объяснениями.
- `components/sections/ApproachSection.jsx` — четыре видеопрактики, без повторения образовательного ролика.
- Кнопки Play — стеклянные; на телефоне карточки идут вертикально и не выходят за ширину экрана.

## Мобильная версия

Адаптивные правила настроены для узких телефонов 320–430px, планшета и desktop:
- Hero: фотография справа, контрастный текст и компактные преимущества внизу.
- Видео-разбор, причины и формат: карточки перестраиваются в одну колонку, изображения не обрезают важные части.
- Результаты: адаптивная галерея с горизонтальной прокруткой миниатюр и подписью на фото.
- Цена: большая стоимость **12 700 ₽**, полноширинная CTA и без фальшивой скидки.
- FAQ, футер, выбор темы: достаточно крупные кнопки и читаемые ответы.

## Важно перед релизом

- `config/site.js`: подключите настоящую ссылку GetCourse и действительные контакты; текущие кнопки запускают демо-окна, если ссылки пусты.
- Проверьте юридически согласованные противопоказания, цены, заявления об эффектах и согласие на публикацию фото участниц.
- Node 16/Next 13 больше не получают современные патчи безопасности. Локальная версия удобна для вашей среды; перед публикацией лучше перейти на поддерживаемую LTS-версию Node и свежую Next.js.
