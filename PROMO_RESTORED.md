# Акционное предложение — восстановлено

В предыдущем редизайне акционная цена и таймер были удалены из карточки стоимости. Этот выпуск возвращает старую логику в новом дизайне четырёх тем.

## Настройки этой версии по последнему уточнению

- Цена без скидки: **12 700 ₽**
- Акционная цена: **9 700 ₽**
- Дата завершения: **2026-11-01T00:00:00+02:00** (Израиль, зимнее время)
- Экономия: **3 000 ₽**, округлённая скидка **24%**

Цены уточнены пользователем. Дата окончания перенесена из предыдущей версии проекта и требует подтверждения у Марины до публичного запуска.

## Как это работает

- `config/site.js` — цены, время завершения, ссылки.
- `hooks/useCountdown.js` — обратный отсчёт до фиксированной даты.
- `components/ui/Countdown.jsx` — отображение дней, часов, минут, секунд.
- `components/sections/PriceSection.jsx` — цена, зачёркнутая стоимость, экономия, счётчик, список преимуществ и кнопка записи.
- `styles/price.css` — оформляет акцию средствами переменных темы, мобильную сетку и контраст.

Когда дедлайн проходит, блок акции и таймер автоматически скрываются, остаётся полная цена. **Ссылка на оплату по-прежнему должна быть подключена отдельно**, чтобы реальная сумма списания совпадала с актуальной ценой в интерфейсе.

## Запуск на Node 16.20.2

```powershell
npm install
npm run check
npm run dev
```

Текущий стек: Next 13.5.11, React 18.2.0. Эти версии устарели, для публичного запуска рекомендуется обновление на поддерживаемый Node/Next.
